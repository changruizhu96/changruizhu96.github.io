# MR Compare media

This folder stores media used by `_projects/mr-compare.md`.

- `teaser.jpg`: current project card and page teaser image, copied from the MR Compare workflow figure.
- `visual-comparison.jpg`: examples comparing registered reconstructions across the Office and Reception rooms.
- `registration-ratings.jpg`: subjective registration rating distributions from the user study.
- `visual-consistency.jpg`: subjective visual consistency rating distributions from the user study.
- `replica-anisotropy.jpg`: Replica tau-sweep heatmaps for the anisotropy filter evaluation.
- Suggested future additions:
  - `teaser.mp4`: short headset demo or screen recording.
  - `comparison-before.jpg` and `comparison-after.jpg`: images for a visual comparison slider.
  - `result-*.jpg`: representative registered-scene results.

Keep filenames lowercase and update `_projects/mr-compare.md` when replacing placeholders.
